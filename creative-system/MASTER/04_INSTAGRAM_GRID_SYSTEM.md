# 04 — INSTAGRAM GRID SYSTEM

## Primary feed canvas
Design feed pieces at 1080×1350 (4:5) unless another format is explicitly requested. Keep critical text safely away from edges and anticipate Instagram grid cropping.

## Feed rhythm
Do not design isolated posts without considering neighboring energy. Alternate:
- photographic / typographic;
- dark / light;
- close / wide;
- human / object;
- polished final work / raw process;
- statement / proof.

## Suggested sequence logic
CLIENT → IDEA → PERSON → DATA → REEL → G.CL → CLIENT → INSIGHT → BACKSTAGE.
This is a rhythm guide, not a rigid calendar.

## Carousel rule
A carousel must behave like a campaign sequence, not a PowerPoint.
Slide 1 = irresistible visual hook.
Slides 2–N = one thought per frame, with visual progression.
Last slide = payoff/action, not generic “contact us.”
Reduce copy until each frame can be understood in seconds.

## Branding
Do not place the logo automatically. Brand recognition should come from the system. When logo is necessary, integrate it intentionally and keep it secondary unless the concept makes it the hero.
