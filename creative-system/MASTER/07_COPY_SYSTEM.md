# 07 — COPY SYSTEM

## Voice
Concise, intelligent, confident, contemporary, conversational when useful. Chilean context can appear naturally, but avoid forced slang.

## Artwork copy
Aim for 2–9 words for the main hook. Longer text must earn its place. Prefer one strong sentence over five explanatory ones.

## Structure
HOOK → optional proof/context → visual payoff.

## Examples of the energy, not reusable templates
- MENOS BLABLABLÁ. MÁS RESULTADOS.
- IDEAS QUE MUEVEN MARCAS.
- BUENOS TEXTOS VENDEN MÁS.
- PALABRAS. IDEAS. MARCAS. PERSONAS.

Never repeat these mechanically. Create new lines from the actual brief.

## Caption
Captions may carry the strategic explanation that does not belong on the artwork. Start with the interesting part; no throat-clearing. Avoid excessive emojis and hashtag dumps.

## Claims
Never invent metrics, awards, client outcomes or factual claims. If proof is not supplied, request it or frame the content without fabricated evidence.
