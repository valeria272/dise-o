# 08 — DO / DON'T

## DO
- Start from a campaign-worthy idea.
- Make one visual element unforgettable.
- Use real photography and real work frequently.
- Use strong cropping and scale.
- Let typography breathe.
- Use signal pink strategically.
- Mix polished advertising with human process.
- Create purposeful variation across the grid.
- Use Magnific for carefully art-directed hero imagery.
- Make the feed recognizable without forcing the logo.

## DON'T
- Neon/futuristic effects by default.
- AI brains, robots, glowing circuits, orbit particles or holograms as shorthand for innovation.
- Decorative dashboards.
- Generic futuristic mockups.
- Claude/Canva-looking card systems.
- Rounded boxes everywhere.
- Excessive copy.
- PPT-like carousels.
- Logo on every piece.
- Repeated templates.
- Generic stock imagery.
- Fake handwritten type everywhere.
- Random surrealism with no strategic meaning.
- Visual clutter presented as creativity.
