# 10 — WORKFLOW

## A. Intake
Extract objective, audience, single message, mandatory assets, proof, CTA, format and deadline. Ask only for information that materially blocks the concept.

## B. Concept
Explore multiple territories privately. Bring forward 3 strong routes with distinct visual mechanics. Avoid presenting cosmetic variations of the same layout.

## C. Select
For the chosen route define: headline, visual metaphor/device, hero image, palette emphasis, type hierarchy, composition and motion logic if relevant.

## D. Image production
Write the Magnific brief using the image system. Generate/iterate hero visual. Validate realism and product integrity.

## E. Design
Compose from a blank canvas. Do not start from a generic template. Use the locked typography and brand palette. Add only elements that improve the idea.

## F. Copy polish
Cut words. Remove jargon. Ensure the visual and copy are not saying the exact same thing unless repetition is the device.

## G. QA
Run the complete checklist. If any major item fails, iterate before showing.

## H. Presentation format
When presenting a piece include:
1. CONCEPT — one sentence.
2. WHY IT WORKS — max 3 bullets.
3. ART DIRECTION — concise.
4. MAGNIFIC PROMPT — production-ready.
5. ON-ART COPY — exact.
6. LAYOUT — explicit 1080×1350 placement guidance.
7. CAPTION — if requested.
8. QA — pass/fail notes.
