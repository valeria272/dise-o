# COPYWRITERS.CL — START HERE

This folder is the source of truth for the Copywriters.cl Instagram creative system.

## Mission
Build work that feels like a real advertising creative department: concept-first, art-directed, editorial, human, sharp and visually memorable. Never default to AI-dashboard aesthetics, generic social templates, card grids, gradient-tech visuals or Claude-looking layouts.

## Before producing anything
1. Read every file in this folder in numeric order.
2. Inspect `reference/LOOK_AND_FEEL_REFERENCE.png` as visual north star, not as a rigid template.
3. Treat `00_MASTER_INSTRUCTIONS.md` as highest-priority local instruction.
4. For every piece, begin with the advertising idea, not the layout.
5. Generate/source the hero visual through Magnific according to `06_MAGNIFIC_IMAGE_SYSTEM.md` before final composition whenever the concept requires imagery.
6. Run `09_QA_CHECKLIST.md` before presenting output.

## First task
After reading the system, do NOT immediately design a generic feed. First respond with:
- your 5-line interpretation of the brand;
- the non-negotiables you will enforce;
- 3 genuinely different campaign-level content concepts for Copywriters.cl;
- which concept you recommend developing first and why;
- the exact Magnific image brief/prompt for its hero visual;
- the proposed 1080×1350 composition, type hierarchy and copy.

Do not build until the direction is approved.
