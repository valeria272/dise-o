# MOTION

Todo el criterio está en [`../MOTION_PLAYBOOK.md`](../MOTION_PLAYBOOK.md).

Esta carpeta guarda lo que produce el motion cuando exista: guiones de reel,
storyboards y specs de escena. Al 03-09-2026 está vacía a propósito — el lote v1
entregó el **cover** (`src/compositions/copylab/ReelCover.tsx`), no el reel
montado.

## Lo mínimo que tiene que traer un guion de reel

```
REEL / ###        <duración objetivo>
INSIGHT
IDEA
0:00  <plano>  ·  <texto en pantalla>
0:02  …
CIERRE            <con logo — es uno de los 4 casos permitidos>
SONIDO            <incluyendo dónde va el silencio>
```

El silencio se planifica igual que un plano. No es la ausencia de banda: es una
decisión.
