# 04 · PROOF

Resultados. **NO dashboards. NO infografías genéricas.**

## La regla

**El número tiene que convertirse en un objeto visual.**

- `+189%` → objetos que físicamente crecen.
- `3,2X` → una repetición visual.
- `−37%` → algo que desciende, se corta o se pierde.

El dato es el protagonista. La interpretación va debajo, en EDITORIAL, y es
secundaria: *«Bajamos el costo. No la ambición.»*

## ⚠️ Regla dura: ningún dato inventado

Un número en una pieza PROOF es una afirmación pública sobre el negocio de un
cliente. Si no viene de una medición auditada **no se publica**, ni «de ejemplo».

La pieza `04-proof` del lote v1 lleva un **−37% de maqueta**, declarado en la
cabecera del archivo y en `ENTREGA.md`. Se reemplaza antes de publicar, y sólo
entonces se puede nombrar al cliente.

Índice: `CASE / <DISCIPLINA>` — sin cliente mientras el dato sea de maqueta.

**Referencia trabajada:** `src/compositions/copylab/Proof.tsx`. La cifra está
literalmente **cortada**: el 37% de abajo se desprendió y cayó, en rosado. El
dato no se ilustra, se ejecuta sobre sí mismo.
