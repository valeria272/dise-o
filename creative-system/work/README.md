# 03 · WORK

Trabajo de clientes **como publicidad**, nunca como ficha de portafolio.

## Prohibido — dos cosas, y la segunda es nueva

1. **La ficha corporativa:** `CLIENTE / SERVICIO / DESCRIPCIÓN / RESULTADO`.
2. **Inventarle campañas al cliente.** WORK muestra **qué hizo Copywriters de
   verdad**. Una pieza WORK con un titular que suena bien pero que nunca existió
   como trabajo no es dirección de arte: es una campaña falsa con el logo de un
   cliente real encima.

## Qué se puede contar

brief · problema · insight · idea · craft · resultado · behind the scenes ·
pieza final.

**Contado editorialmente**, nunca como case study corporativo. Se elige UNA de
esas entradas por pieza — la que tenga la mejor historia — y se cuenta como se
contaría en una revista, no en un PowerPoint.

> **Lo que WORK necesita de la cuenta antes de producirse:** el problema real, la
> idea real y, si se va a mostrar un número, el dato auditado. Sin eso, una pieza
> WORK no se diseña. Es el único caso del sistema en que la producción se bloquea
> esperando input — y se bloquea a propósito.

## La regla que manda

**La estética de cada WORK respeta el universo del cliente. Copywriters agrega
sólo una capa editorial mínima.**

Eso significa que la voz que titula **cambia según el cliente**:

| Cliente | Registro | Voz que titula |
|---|---|---|
| Traverso (alimentos, popular, directo) | contundente | IMPACTO condensada |
| Cava Morandé (vino, premium, sereno) | editorial | EDITORIAL cursiva |

Titular una pieza de Cava en condensada negra sería imponerle el sistema de la
agencia encima de su marca. Es el error que esta familia existe para evitar.

El packshot es **real**, del e-commerce o del brandbook del cliente. La IA hace
el ambiente y nada más. Ver `IMAGE_GENERATION_PLAYBOOK.md` → «Composición con
producto real».
