**Plan pago de Canva disponible** (recordatorio de Valeria, 22-08-2026): además de Higgsfield
y Magnific, la agencia paga Canva. Incluye diseño (piezas, carruseles, presentaciones, video),
**Magic Studio / IA** (generación de imágenes, Magic Edit, Magic Expand, quitar fondo,
Magic Write), brand kit (`kAF_gMI0GAg`), plantillas y exportación.

Acceso desde Claude Code: **conector MCP de claude.ai** (`mcp__claude_ai_Canva__*`:
generate-design, edit-design, export-design, upload-asset-from-url, list-brand-kits,
search-designs, create-design-from-brand-template, etc.), sin API key. Como todo conector,
si no aparece hay que reconectarlo en claude.ai → Connectors y abrir chat nuevo.

**Why:** cuando Higgsfield queda sin créditos o Magnific no alcanza (pasó con MyZoo, 21-08),
Canva es una alternativa pagada que ya tenemos — no hay que asumir que "no hay con qué
generar". También sirve para entregar editables que diseñadores/clientes pueden retocar.

**How to apply:** al planificar imágenes/piezas, poner Canva en la lista de opciones
(diseño + IA + gen. de imágenes). ⚠️ Matiz: para reels premium con visuales IA
cinematográficos Valeria prefirió Higgsfield por estética (ver [[reel-ai-pipeline]]) — eso
fue una preferencia de look para ese caso, no un veto general a Canva. Relacionado:
[[myzoo-web-imagenes]], [[ebema-click-mailings]].
