# VISUAL SYSTEM

## Palette
Primary: near-black / off-white / hot pink.
Secondary neutrals: charcoal, paper white, warm grey.
Client colors may enter only when the piece is explicitly a WORK/CLIENT WORLD piece.

## Typography hierarchy
1. DISPLAY SANS — condensed/heavy uppercase for hooks and impact.
2. EDITORIAL SERIF — italic/high-contrast for counterpoint, punchline, nuance.
3. MONO — metadata: SIGNAL / 041, WORK / CLIENT, timestamps, episode numbers.
4. HANDWRITTEN — annotations, arrows, circles, “found” comments. Use sparingly.

## Composition
Large type, confident negative space, one dominant idea.
Pink is punctuation, not wallpaper.
Metadata is quiet and systematic.
Photography can carry type but must retain a clear focal hierarchy.

## Advertising games
Strike-through that changes meaning.
Circle/underline as editorial correction.
Before/after semantic flips.
Scale exaggeration of one data point.
Literal visual metaphors.
Unexpected object substitutions.
Copy that sets up one meaning and a serif/pink line that overturns it.
